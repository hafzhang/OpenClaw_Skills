# 教程质量检查清单

本文档提供了完整的教程质量检查清单，确保发布的教程符合标准。

## 使用说明

- 使用此清单对教程进行全面检查
- 所有项目必须通过（打勾）才能发布
- 对于不适用（N/A）的项目，注明原因
- 记录检查日期和检查人

---

## 1. 内容完整性

### 基本信息
- [ ] 教程 ID 遵循命名规范（tutorial-XXX）
- [ ] 标题清晰描述主题，包含关键词
- [ ] slug 使用 kebab-case，URL 友好
- [ ] 描述简洁准确（1-2 句话）
- [ ] 作者信息完整
- [ ] 创建日期正确

### 前置条件
- [ ] 前置条件完整列出
- [ ] 包含必需的工具/软件
- [ ] 包含必需的知识基础
- [ ] 包含前置教程引用（如有）
- [ ] 说明账号/权限要求

### 学习目标
- [ ] 目标具体可衡量
- [ ] 使用 SMART 原则
- [ ] 覆盖教程核心内容
- [ ] 与实际内容一致
- [ ] 数量适当（4-6 个）

### 内容结构
- [ ] 包含所有标准章节
- [ ] 章节顺序合理
- [ ] 逻辑流程清晰
- [ ] 没有遗漏重要内容
- [ ] 字数符合难度要求：
  - Beginner: 2000+ 字
  - Intermediate: 2500+ 字
  - Advanced: 3000+ 字

### 实战步骤
- [ ] 每个步骤目的明确
- [ ] 步骤编号连续
- [ ] 包含操作说明
- [ ] 包含预期结果
- [ ] 包含注意事项

## 2. 代码质量

### 代码示例
- [ ] 所有代码块指定语言标识符

- [ ] 没有硬编码敏感信息

### 代码数量
- [ ] Beginner: 至少 5 个代码示例
- [ ] Intermediate: 至少 6 个代码示例
- [ ] Advanced: 至少 8 个代码示例

### 代码验证

- [ ] 输出示例准确

### 命令行代码

- [ ] 命令前有说明注释
- [ ] 包含预期输出
- [ ] 长命令正确换行
- [ ] 跨平台命令有说明
