## Codebase Patterns
- This is a Next.js 16 project with TypeScript and Tailwind CSS v3.4.17
- Uses static export (output: 'export') for deployment
- shadcn/ui for UI components
- Markdown content stored in src/data/tutorials.json (content field contains Markdown)
- Data files in src/data/ (JSON format)
- Types defined in src/types/index.ts
- Dynamic routes use [param] directory naming (e.g., [slug])
- For static generation with dynamic routes, use generateStaticParams() + dynamicParams = false
- ReactMarkdown components prop requires `as Components` type assertion
- highlight.js for code syntax highlighting (import styles separately)
- Tutorial IDs: format is `tutorial-XXX` where XXX is incrementing from 001
- When adding new tutorials: read end of tutorials.json to find last ID, remove closing bracket `]`, add new tutorials, add back closing bracket
- Build generates static pages: tutorials create /tutorial/[slug] routes, skills create /skills/[slug] routes
- Number of static pages = number of tutorials + number of skills + other pages
- For skill research verification: use scripts/verify-repos-batch2.js pattern for checking GitHub repo accessibility
- Large repositories (10k+ stars) often timeout during HEAD requests but are still valid

- GitHub Actions 社区操作: Checkout (5.3k) 是代码检出标准，Setup-* 系列用于配置运行环境
- GitLab CI/CD: GitLab Runner 是自托管运行器，但主要代码托管在 GitLab 自己的 GitLab 实例而非 GitHub
- Jenkins: Jenkins (23k) 是传统 CI/CD 服务器，Kubernetes Plugin (2.8k) 提供 K8s 集成
- Drone CI: 被 Harness 收购，仓库迁移到 harness 组织，Drone (31k) 是容器原生 CI 平台
- 构建系统: Nx (23k) 是单体仓库工具，Turborepo (25k) 是高性能构建系统，Bazel (23k) 是 Google 开源的多语言构建系统
- 404 仓库原因: GitHub Actions 子模块托管在 toolkit 仓库下，GitLab 项目不托管在 GitHub
- TIMEOUT 仓库大多是大型知名项目 (nx, turborepo, bazel, dagger, earthly)，仍然有效
