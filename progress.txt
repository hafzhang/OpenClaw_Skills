## Codebase Patterns
- This is a Next.js 14 project with TypeScript and Tailwind CSS
- Uses static export (output: 'export') for deployment
- shadcn/ui for UI components
- Markdown content stored in src/data/tutorials.json (content field contains Markdown)
- Data files in src/data/ (JSON format)
- Types defined in src/types/index.ts
- Dynamic routes use [param] directory naming (e.g., [slug])
- For static generation with dynamic routes, use generateStaticParams() + dynamicParams = false
- ReactMarkdown components prop requires `as Components` type assertion
- highlight.js for code syntax highlighting (import styles separately)
