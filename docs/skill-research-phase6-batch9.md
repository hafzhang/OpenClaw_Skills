### 404 仓库分析

大多数 404 仓库的原因：
- **Notion SDK**: 官方 SDK 仓库可能使用不同的组织名称或子路径
- **Obsidian 插件**: 一些插件可能已迁移到 obsidianmd 组织，或使用不同的仓库名
- **Logseq 插件**: 一些插件可能不再维护或已合并到主仓库
- **Joplin iOS/插件**: iOS 仓库可能已改名或合并，插件可能在不同的组织下
- **Trilium Notes**: 主仓库可能使用不同的路径
- **Foam**: VS Code 扩展可能已迁移到 foambubble 或其他组织
